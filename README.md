# Actividad-02-comandos-b-sicos
*Trabajo de Introducción a la Ciencia de Datos*

## Descripción 
El proposito es comprender y poner en practica las herramientas Git y Github para el control de versiones, la organizacion de archivos y la documentación de los cambios realizados en un proyecto
En esta actividad se desarrolla un tutorial basado en el libro Git 2nd Edition en el que se presentan conceptos fundamentales y comandos basicos utilizados para administrar repositorios.

## Objetivo General
Comprender y utilizar las herramientas Git y Github para su creación y control de un repositorio personal, registrar los cambios en documentos.


## Objetivos específicos: 
1.	Crear una cuenta en GitHub e Instalar Git
2.	Cree un nuevo repositorio en GitHub y clonarlo en el equipo local
3.	Construya documentos en microsoft word donde presente un tutorial de Git, realice cada capítulo en un documento de word diferente
4.	Documentar el proceso

## Herramientas utilizadas 


- **Git:** Sistema de control de versiones 

- **Github:** Plataforma para alojar y administrar repositorios remotos

- **Github desktop:** Aplicación para la gestión y control de repositorios y sincronizar cambios 

- **Word:** Herramientas para elaborar los documentos

- **PDF:** Formato de exportación para los documentos


## Estructura del repositorio
- **README.md:** documento que describe el proyecto y el proceso realizado.

- **documentos/:** carpeta destinada a los archivos de los capítulos del tutorial, en formatos TXT, Word y PDF.

- **evidencias/:** carpeta destinada a almacenar las capturas de pantalla del desarrollo de la actividad.

- **Informe de proceso.pdf:** informe final con la descripción de las actividades, evidencias, dificultades, soluciones y conclusiones.


## Procedimiento Realizado
1. Creación de una cuenta personal en GitHub.
2. Creación del repositorio para la actividad.
3. Clonación del repositorio mediante GitHub Desktop.
4. Creación y organización de carpetas y archivos.
5. Elaboración de documentos de texto y del tutorial en Microsoft Word.
6. Exportación de los documentos a PDF.
7. Registro de los cambios mediante commits con mensajes descriptivos.
8. Publicación de los cambios en GitHub.
9. Documentación del proceso mediante capturas de pantalla e informe final

## Conclusion
Esta actividad permite comprender la importancia del control de versiones en los proyectos de software y ciencia de datos.
